# Raw source data

This directory contains captured and intermediate source data organized by list. The generated, app-ready CSV files remain in the parent `data/` directory.

- `biblioguides/`: HTML capture and source manifest
- `john-senior/`: extracted PDF records
- `inventory/`: LibraryThing export of currently owned books
- `plumfield-living-library/`: LibraryThing capture
- `read-aloud-revival/`: paginated website captures
- `reshelving-alexandria/`: Notion capture
